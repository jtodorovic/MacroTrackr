# MacroTrackr

**MacroTrackr** is a comprehensive health and fitness tracking platform that enables users to monitor their daily macronutrient intake, log meals efficiently, and achieve fitness goals. Designed for scalability and reliability, it provides a robust backend, secure authentication, and flexible tracking features suitable for both individual users and production applications.

---

## Features

- **Food Logging:** Log meals quickly with nutritional details.
- **Macro Tracking:** Track daily intake of calories, protein, carbohydrates, and fats.
- **Custom Goals:** Set personalized macronutrient and calorie targets.
- **AI Recommendationa:** AI recipe recommendations based on user goal.
- **Secure Authentication:** JWT-based user authentication.

---

## Tech Stack

- **Backend:** Golang, Gin
- **Database:** SQLite, DynamoDB
- **Authentication:** JWT
- **DevOps / Deployment:** Docker, AWS (optional)
